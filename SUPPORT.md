# Getting help

- **Usage questions and ideas:** [GitHub Discussions](https://github.com/myrk-kale/klaub/discussions).
- **Bugs:** open an issue using the bug template and include the output of `klaub doctor`.
- **Security problems:** see [SECURITY.md](SECURITY.md); never use a public issue.
- **Documentation:** start at the [README](README.md) and the [docs](docs/) folder.
